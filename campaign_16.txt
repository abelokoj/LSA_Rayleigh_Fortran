# =====================================================================
# campaign_16.txt -- the October 2026 run campaign at 16 cells per radius.
# =====================================================================
# Read by scripts/run_all.sh (through scripts/submit_campaign.sh). Same columns as full_analysis.txt, plus optional make_inputs options after the seventh column:
#
#   label  kr0  eps  cells_per_r0  rmax  n_periods  snapshots  [options]
#
# With --eps-cells C the amplitude used is C * dr and the eps column is only a label (it must be positive; a zero means "twin").
#
# Why these cases. The archived study (September 2026 evidence report) established the reference rate at k r0 = 0.7 from small-amplitude runs (meas08/16/32, eps = 5e-3), but everything else was run at eps = 2e-2, which reaches a/r0 = 0.1 before the startup transient has decayed: re-fitting those records with run_lsa record leaves windows of only 0.2 e-folds (res08/16/32, disp*, domain06). No DMD result was kept, and no twin exists beside meas16 or meas32. This file supplies what is missing, at the resolution the thesis needs (at least 16 cells per radius, Chapter 5):
#
#   A. dispersion sweep at a small amplitude, with twins, so that every wavenumber has both an interface rate and a DMD rate over a clean window;
#   B. proportionality over the whole fitting interval (the archived amplitude sweep stopped at t = 3.6);
#   C. a time-step refinement at fixed grid (never done);
#   D. one-at-a-time changes of the outer wall, the gas density and the gas viscosity;
#   E. the stable-band control, long enough to see the oscillation, with signed coefficients.
#
# Amplitude. eps = 0.04 dr = 2.5e-3 at 16 cells (--eps-cells 0.04, the eps = c dx prescription of dissertation eq:4_norm). Halving the amplitude of the meas runs buys ln 2 = 0.69 e-folds more of clean window before a/r0 = 0.1. n_periods = 4.3 ends the run just past that bound: ln(0.1/0.0025) = 3.7 e-folds plus about half an e-fold of startup lag. Running further only adds nonlinear data.
#
# Snapshots. 160 per run gives about 40 samples in the admissible window, enough for the window fit and for DMD; more only costs disk and I/O.
#
# Twins. One .base per wavenumber; the base state does not depend on eps, so sw070_16.base also serves lin050_16 and lin100_16. Twins and perturbed runs MUST be in the same array submission so that they run on the same rank count and build.
#
# Order. Longest first, so the array finishes as early as possible. The three longest wavenumbers are in campaign_16_wide.txt, submitted with twice the ranks.
# =====================================================================
